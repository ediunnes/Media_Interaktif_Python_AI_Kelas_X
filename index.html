Dasar Pemrograman Python untuk Kecerdasan Artifisial

Tujuan pembelajaran

  • Menjelaskan variabel, struktur kontrol, dan fungsi.
  • Menulis kode sederhana menggunakan variabel dan percabangan.
  • Membuat fungsi sederhana untuk menjalankan tugas tertentu.
Pertanyaan pemantik: Bagaimana komputer bisa memilih tindakan yang berbeda berdasarkan umur atau nilai yang kita masukkan?
📦

Variabel

Tempat menyimpan data agar bisa digunakan kembali.

nama = "Ayu"
umur = 16
print(nama, umur)
Contoh output: Ayu 16
🔀

Struktur kontrol

if–else memilih tindakan sesuai kondisi.

if umur >= 18:
    print("Dewasa")
else:
    print("Belum dewasa")
Indentasi menentukan blok kode.
🧩

Fungsi

Kumpulan perintah bernama yang dapat dipanggil kembali.

def sapa(nama):
    return "Halo, " + nama

print(sapa("Ayu"))
Contoh output: Halo, Ayu

Mengapa Python untuk AI?

Python memiliki sintaks yang relatif mudah dibaca dan banyak pustaka untuk analisis data, machine learning, deep learning, computer vision, serta pemrosesan bahasa. Pada pembelajaran ini, kita berlatih fondasi pemrogramannya terlebih dahulu.

Laboratorium kode mini

Ubah nama dan umur, lalu jalankan simulasi. Ini adalah simulasi di halaman ini; untuk menjalankan Python sungguhan, gunakan Google Colab.

1. Variabel

nama = "..." 
umur = ...
print("Halo,", nama, "umur kamu", umur, "tahun")
Output akan tampil di sini.

2. Struktur kontrol if–else

if umur >= 18:
    print("Kamu sudah dewasa.")
else:
    print("Kamu belum dewasa.")
Output akan tampil di sini.

3. Fungsi

def sapa(nama):
    return "Selamat belajar Python, " + nama + "!"

print(sapa(nama))
Output akan tampil di sini.
Tantangan kelompok: Ubah batas kondisi dari 18 menjadi 17. Prediksi output untuk umur 17 sebelum menekan tombol. Diskusikan alasan hasilnya dengan teman.

Langkah menggunakan Google Colab

  1. Buka colab.google dan buat notebook baru.
  2. Salin kode dari tiap contoh ke sel kode terpisah.
  3. Tekan tombol ▶ pada sel untuk menjalankan kode.
  4. Jika muncul error, periksa tanda kutip, titik dua, dan indentasi.
  5. Simpan notebook dengan nama Latihan_Python_NamaKelompok di Google Drive.
